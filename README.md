# PWM Generator — трёхканальный генератор на Raspberry Pi Pico W + Android-приложение

Архив проекта: прошивка платы, Android-приложение, веб-интерфейс для ПК и готовые APK.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `firmware/` | Прошивка MicroPython. `FINAL все работает.py` — актуальная, версия **10_32** (заливать на Pico W как `main.py`). `2040_zero_main.py` — вариант для RP2040 Zero (USB). `boot.py` |
| `web/` | Веб-интерфейс для ПК: `index_wifi.html` (по Wi-Fi), `index.html` |
| `apk/` | Готовые сборки приложения. `PWMGen-1.6.3-h3.apk` — актуальная |
| `pc/` | `POBEDA.zip` — программа управления для ПК (внутри `POBEDA.exe`, распаковать и запустить) |
| `app/`, `gradle/`, `gradlew` | Исходники Android-приложения (собирается через GitHub Actions) |

## Перед заливкой прошивки

В `firmware/FINAL все работает.py` имя и пароль домашней сети очищены — впишите свои между кавычками:

```python
HOME_SSID = ""
HOME_PASS = ""
STATIC_IP = "192.168.0.222"
```

Если оставить `HOME_SSID` пустым, плата поднимет только свою точку доступа и будет доступна по `192.168.4.1`.

## Связь с приложением

- Точка доступа платы: SSID `PWMGen`, без пароля, плата на `192.168.4.1`
- В домашней сети — по статическому адресу из `STATIC_IP`
- Android ↔ плата: **UDP, порт 8889**. TCP 8888 — ПК и OTA
- В приложении адрес задаётся долгим нажатием кнопки подключения → «Подключение» → WiFi

Признак настоящей связи — ползунки сами встают в значения платы. Индикатор ONLINE загорается ещё до ответа платы, ориентироваться на него нельзя.

## Протокол команд

Текстовая строка `КЛЮЧ:ЧИСЛО\n`, в ответ — статус JSON одной строкой.

| Команда | Значение |
|---|---|
| `F1:` / `D1:` | частота и скважность CH1/CH2 |
| `F3:` / `D3:` | частота и скважность CH3 |
| `FC:` | несущая частота CH3 |
| `N3:` | импульсов в пачке |
| `P3:` | фаза CH3, ‰ |
| `H3:` | пропуск периодов CH1: `0` — пачка каждый период, `5` — через пять (0…20) |
| `X2:` `LK:` `IV:` `PL:` `PM:` | ×2, привязка CH3 к CH1, инверсия, ФАПЧ и её режим |
| `GET` | запрос статуса |

## Сборка APK

GitHub → Actions → workflow **Build APK** → артефакт `pwmgen-debug`.

Локально: `./gradlew assembleDebug` (JDK 17, Android SDK 35). Путь к проекту **без кириллицы** — иначе AGP останавливает сборку.
